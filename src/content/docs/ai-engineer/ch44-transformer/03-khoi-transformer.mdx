## Bốn thành phần

Một khối <Term id="transformer">Transformer</Term> (phần mã hóa) gồm:

1. **Self-attention nhiều đầu** (trang 2): mỗi token trộn thông tin từ các token khác.
2. **Mạng truyền thẳng** (feed-forward): một MLP hai lớp (Chương 23) áp lên **từng token riêng lẻ**, cùng trọng số cho mọi vị trí. Attention trao đổi thông tin giữa các token; mạng truyền thẳng xử lý thông tin trong từng token. Lớp ẩn thường rộng gấp 2 tới 4 lần $d$.
3. **Kết nối tắt** (Chương 28) quanh mỗi phần: $x + f(x)$, để tín hiệu và gradient đi thẳng qua nhiều khối.
4. **LayerNorm** (Chương 26): chuẩn hóa mỗi vector token về trung bình 0, phương sai 1 trước mỗi phần (cách đặt "pre-norm", ổn định hơn cách đặt sau trong bài báo gốc).

Ghép lại thành mô hình phân loại: vector từ nhân $\sqrt{d}$, cộng mã hóa vị trí (bật tắt được bằng `vt`), chồng các khối, rồi lấy **trung bình** vector của các token thật (bỏ ô đệm) làm vector câu, cuối cùng một lớp tuyến tính.

```python
class Khoi(nn.Module):
    def __init__(self, d, h, f):
        super().__init__()
        self.att, self.n1 = MultiHead(d, h), nn.LayerNorm(d)
        self.ff = nn.Sequential(nn.Linear(d, f), nn.GELU(), nn.Linear(f, d))   # mạng truyền thẳng từng token
        self.n2, self.drop = nn.LayerNorm(d), nn.Dropout(0.1)
    def forward(self, x, mask):
        x = x + self.drop(self.att(self.n1(x), mask))   # kết nối tắt quanh attention
        return x + self.drop(self.ff(self.n2(x)))      # kết nối tắt quanh mạng truyền thẳng

class Transformer(nn.Module):
    def __init__(self, V, so_lop=3, d=128, h=4, f=256, L=2, vt=True, toi_da=64):
        super().__init__()
        self.emb, self.vt = nn.Embedding(V, d, padding_idx=0), vt
        self.register_buffer("P", vi_tri(toi_da, d))    # mã hóa vị trí cố định, không học
        self.khoi = nn.ModuleList([Khoi(d, h, f) for _ in range(L)])
        self.n, self.ra = nn.LayerNorm(d), nn.Linear(d, so_lop)
    def forward(self, x):
        mask = x != 0
        z = self.emb(x) * math.sqrt(self.emb.embedding_dim)
        if self.vt:
            z = z + self.P[:x.shape[1]]
        for k in self.khoi:
            z = k(z, mask)
        z = self.n(z)
        z = (z * mask[..., None]).sum(1) / mask.sum(1, keepdim=True)   # trung bình các token thật
        return self.ra(z)
```

Hai khối, $d = 128$, 4 đầu, lớp ẩn truyền thẳng 256. Mỗi khối có khoảng 132 nghìn tham số: 66 nghìn ở attention, 66 nghìn ở mạng truyền thẳng. Với từ điển 1535 âm tiết của trang 4, bảng vector từ có thêm 196 nghìn.

## Thứ tự có quan trọng không

Trang 2 nói không có mã hóa vị trí thì Transformer không phân biệt được thứ tự. Kiểm trên một bài toán mà thứ tự là **tất cả**: mỗi chuỗi có 12 token ngẫu nhiên (từ điển 22 token), trong đó có đúng một token A (số 1) và một token B (số 2) ở vị trí ngẫu nhiên. Nhãn: A có đứng trước B không. Tập các token của hai chuỗi "A trước B" và "B trước A" có thể y hệt nhau, chỉ khác thứ tự.

```python
def tao(n, seed):
    g = torch.Generator().manual_seed(seed)
    X = torch.randint(3, 22, (n, 12), generator=g)   # token "nhiễu" từ 3 tới 21
    for i in range(n):
        a, b = torch.randperm(12, generator=g)[:2].tolist()
        X[i, a], X[i, b] = 1, 2                      # đặt A và B
    y = ((X == 1).float().argmax(1) < (X == 2).float().argmax(1)).long()   # A trước B
    return X, y

X_ab, y_ab = tao(5000, 0)
X_ab_va, y_ab_va = tao(1000, 1)

def hoc_thu_tu(vt, so_epoch=10):

    opt = torch.optim.AdamW(m.parameters(), lr=1e-3, fused=True)   # fused: lặp lại được trên CPU
    for ep in range(1, so_epoch + 1):
        m.train()
        thu_tu = torch.randperm(5000)

            loss = F.cross_entropy(m(X_ab[idx]), y_ab[idx])
            opt.zero_grad()
            loss.backward()
            opt.step()
        m.eval()
```
