## Colab là gì

Google Colab là một notebook Jupyter chạy trên máy chủ của Google, mở bằng trình duyệt. Bạn cần một tài khoản Google, và thế là xong: Python, NumPy, pandas, scikit-learn, PyTorch đều cài sẵn. Bản miễn phí đủ cho mọi chương của Phần I và II; từ Phần III, bạn sẽ cần GPU, Colab miễn phí cũng có (có giới hạn thời gian dùng mỗi ngày).

Notebook là một tài liệu gồm các **ô** <En>cell</En>. Ô chữ chứa giải thích, ô code chứa Python. Chạy một ô code thì kết quả hiện ngay bên dưới ô đó.

## Mở notebook của một chương

Đầu trang đầu tiên của mỗi chương có nút **Open in Colab**. Bấm vào, Colab mở đúng notebook của chương đó từ GitHub. Trang [Notebook](/notebook/) liệt kê notebook của mọi chương đã viết.

## Chạy ô code

- Bấm vào ô, nhấn **Shift + Enter**: chạy ô đó và nhảy xuống ô kế tiếp.
- Menu **Runtime > Run all**: chạy cả notebook từ trên xuống.
- Ô đang chạy có biểu tượng xoay tròn. Ô chạy xong có số thứ tự trong ngoặc vuông bên trái, ví dụ `[3]`: ô thứ ba được chạy.

Thử với ô đầu tiên của notebook chương này:

```python
import sys, numpy, pandas, sklearn, matplotlib
print(sys.version.split()[0], numpy.__version__, pandas.__version__, sklearn.__version__, matplotlib.__version__)
```

```text title="Output"
3.12.14 2.5.4 3.1.0 1.9.1 3.11.2
```

Đây là phiên bản Python và thư viện mà giáo trình dùng để chạy mọi output in trong bài. Colab của bạn có thể có phiên bản khác. Phần lớn code vẫn chạy y hệt; chỗ nào kết quả phụ thuộc phiên bản (như dãy số ngẫu nhiên), bài sẽ ghi rõ.

Các ô của một notebook dùng chung biến. Ô 5 dùng biến `x` mà ô 2 tạo ra. Nếu bạn mở notebook rồi chạy thẳng ô 5, Python báo `NameError: name 'x' is not defined`.

## Lưu bản của riêng bạn

Notebook mở từ GitHub là bản **chỉ đọc**. Bạn sửa và chạy thoải mái, nhưng đóng tab là mất. Muốn giữ: menu **File > Save a copy in Drive**. Colab tạo một bản trong thư mục `Colab Notebooks` của Google Drive, từ đó bạn sửa và lưu như một tài liệu bình thường.

File dữ liệu mà notebook tạo ra (như `lop10.csv` ở Chương 4) nằm trên máy chủ tạm của Colab, bấm biểu tượng thư mục ở thanh bên trái để thấy. Chúng **bị xóa** khi phiên làm việc kết thúc (sau một thời gian không dùng). Muốn giữ, tải về máy hoặc gắn Google Drive.

## Đổi sang GPU

Từ Chương 25 (PyTorch), nhiều notebook chạy nhanh hơn hàng chục lần trên GPU. Menu **Runtime > Change runtime type**, chọn **T4 GPU**, bấm Save. Kiểm tra:

```python
import torch
print(torch.cuda.is_available())     # True nghĩa là đang có GPU
```

Bản miễn phí giới hạn số giờ GPU mỗi ngày, và Colab có thể ngắt kết nối nếu bạn để yên lâu. Chỉ bật GPU khi chương cần, mỗi notebook đều ghi rõ ở ô đầu.

## Cài thêm thư viện

Thư viện nào chưa có sẵn, cài bằng một ô có dấu chấm than ở đầu:

```python
!pip install underthesea
```

Dấu `!` báo Colab chạy lệnh đó trên dòng lệnh của máy chủ thay vì như code Python. Thư viện cài kiểu này cũng mất khi phiên kết thúc, nên các notebook cần thư viện ngoài đều có sẵn ô cài ở đầu.
