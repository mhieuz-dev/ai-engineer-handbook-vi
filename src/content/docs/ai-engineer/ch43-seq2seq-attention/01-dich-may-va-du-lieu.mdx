## Chuỗi sang chuỗi

Phân loại (Chương 41) đọc một câu và trả ra **một** nhãn. Gán nhãn chuỗi (Chương 42) trả ra đúng **một nhãn cho mỗi token**, nên đầu ra dài bằng đầu vào. Nhiều bài toán không vừa khuôn nào: **dịch máy** ("I was very proud ." thành "Tôi đã rất tự hào ."), tóm tắt văn bản, trả lời câu hỏi, chuyển giọng nói thành chữ. Đầu vào là một chuỗi, đầu ra là một chuỗi khác, **dài ngắn khác nhau**, và thứ tự không khớp từng cặp. Đó là bài toán <Term id="seq2seq">chuỗi sang chuỗi</Term> (sequence to sequence, seq2seq).

Chương này dịch tiếng Anh sang tiếng Việt, bài toán mà Google Dịch chuyển sang mạng nơ-ron năm 2016. Mục tiêu không phải đánh bại Google Dịch trên một laptop, mà hiểu cơ chế, đo đúng, và thấy vì sao attention ra đời. Attention là ý tưởng mà Transformer (Chương 44) và mọi mô hình ngôn ngữ lớn được xây lên.

```python
import html
import math
import os
import time
import urllib.request
from collections import Counter
import numpy as np
import pandas as pd

URL = ("https://huggingface.co/datasets/thainq107/iwslt2015-en-vi/resolve/"
       "4abfde30435395d5d3f031fea5e3f6600543521e/data/{}-00000-of-00001.parquet")
THU_MUC = os.path.expanduser("~/.cache/iwslt15")

def tai(phan):
    os.makedirs(THU_MUC, exist_ok=True)
    tep = os.path.join(THU_MUC, phan + ".parquet")
    if not os.path.exists(tep):
        urllib.request.urlretrieve(URL.format(phan), tep)
    return pd.read_parquet(tep)

tr, va_goc, te = tai("train"), tai("validation"), tai("test")
print(len(tr), len(va_goc), len(te), va_goc.equals(te))
print(te.en[0])
print(te.vi[0])
```

## Làm sạch và chọn câu ngắn

Văn bản đã được tách token sẵn bằng dấu cách (dấu câu đứng riêng). Ta đổi ký tự HTML, chữ thường, rồi cắt theo dấu cách. Dịch câu dài cần mô hình lớn và nhiều giờ huấn luyện, nên chỉ giữ cặp câu có **3 tới 12 token** ở cả hai phía. Rồi tách ngẫu nhiên 2000 cặp làm val, phần còn lại làm train:

```python
sach = lambda s: html.unescape(s).lower().split()
cap = [(sach(e), sach(v)) for e, v in zip(tr.en, tr.vi)]
cap = [(e, v) for e, v in cap if 3 <= len(e) <= 12 and 3 <= len(v) <= 12]
thu_tu = np.random.default_rng(0).permutation(len(cap))
C_va, C_tr = [cap[i] for i in thu_tu[:2000]], [cap[i] for i in thu_tu[2000:]]
C_te = [(sach(e), sach(v)) for e, v in zip(te.en, te.vi)]
C_te = [(e, v) for e, v in C_te if 3 <= len(e) <= 12 and 3 <= len(v) <= 12]
print(len(cap), len(C_tr), len(C_va), len(C_te))
print(C_te[1])
```

```text title="Output"
(['i', 'was', 'so', 'shocked', '.'], ['tôi', 'đã', 'bị', 'sốc', '.'])
```

## Từ điển

Mỗi ngôn ngữ một từ điển, chỉ giữ từ gặp ít nhất 5 lần trong train; từ hiếm hơn thành `<unk>`. Bốn ký hiệu đặc biệt: `<pad>` (0) để đệm, `<unk>` (1), `<s>` (2) mở đầu câu đích, `</s>` (3) kết thúc câu đích.

```python
def tu_dien(ds, k=5):
    dem = Counter(w for s in ds for w in s)
    tu = ["<pad>", "<unk>", "<s>", "</s>"] + [w for w, n in dem.most_common() if n >= k]
    return tu, {w: i for i, w in enumerate(tu)}

tu_e, id_e = tu_dien([e for e, _ in C_tr])
tu_v, id_v = tu_dien([v for _, v in C_tr])
ma = lambda s, d: [d.get(w, 1) for w in s]           # từ ngoài từ điển thành <unk>
la_v = sum(w not in id_v for _, v in C_va for w in v) / sum(len(v) for _, v in C_va)
print(len(tu_e), len(tu_v), round(la_v, 4))
```

```text title="Output"
2866 2231 0.0331
```

2866 từ tiếng Anh, 2231 từ tiếng Việt. Từ điển tiếng Việt nhỏ hơn dù văn bản tiếng Việt dài hơn: tiếng Việt viết theo âm tiết, và vài nghìn âm tiết ghép thành hầu hết các từ (Chương 38). Khoảng 3,3% token tiếng Việt của val là `<unk>`; mô hình không bao giờ dịch đúng những token đó.
