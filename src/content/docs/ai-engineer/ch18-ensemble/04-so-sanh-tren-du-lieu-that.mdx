## Tiểu đường

```python
from sklearn.ensemble import RandomForestRegressor, GradientBoostingRegressor, HistGradientBoostingRegressor
from sklearn.datasets import load_diabetes
from sklearn.metrics import r2_score
Xd, yd = load_diabetes(return_X_y=True, as_frame=True, scaled=False)
Xdtr, Xdte, ydtr, ydte = train_test_split(Xd, yd, test_size=0.2, random_state=42)
for ten, m in [("cây sâu 3", DecisionTreeRegressor(max_depth=3, random_state=0)),
               ("random forest", RandomForestRegressor(n_estimators=300, random_state=0)),
               ("gradient boosting", GradientBoostingRegressor(random_state=0)),
               ("hist gradient boosting", HistGradientBoostingRegressor(random_state=0))]:
    print(ten, round(r2_score(ydte, m.fit(Xdtr, ydtr).predict(Xdte)), 4))
```

```text title="Output"
cây sâu 3 0.3294
random forest 0.4251
gradient boosting 0.451
hist gradient boosting 0.3866
```

Ensemble kéo $R^2$ từ 0,33 của cây đơn lên 0,43 tới 0,45. Nhưng hồi quy tuyến tính ở Chương 9 đạt 0,4526 trên cùng tập test, ngang mô hình cây tốt nhất. Với 353 bệnh nhân train và một quan hệ gần tuyến tính, không có nhiều phi tuyến để các cây khai thác, còn mỗi bậc thang thêm vào lại thêm nhiễu.

**Bảng 18.3.** Chọn ensemble nào.

| | Random forest | Gradient boosting |
|:---|:---|:---|
| Cách huấn luyện | song song, chạy đa luồng dễ | nối tiếp |
| Núm vặn quan trọng | `max_features`, `min_samples_leaf` | số vòng, learning rate, độ sâu |
| Thêm mô hình con | không bao giờ hại | quá nhiều thì overfit |
| Chỉnh siêu tham số | ít nhạy, mặc định thường ổn | nhạy hơn, đáng chỉnh |
| Độ chính xác tốt nhất | thường kém boosting một chút | thường cao nhất |
