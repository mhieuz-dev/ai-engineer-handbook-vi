## Giữ thứ tự

Mọi mô hình từ trang 1 tới giờ coi câu là một túi n-gram. Chương 40 kết thúc với một lời hứa: đưa vector từ vào một mô hình **giữ được thứ tự** thay vì lấy trung bình. Mô hình ở đây là LSTM (Chương 29) đọc câu từ trái sang phải, cộng một LSTM thứ hai đọc từ phải sang trái: **LSTM hai chiều** (BiLSTM). Trạng thái cuối của hai chiều ghép lại thành vector của câu, rồi một lớp tuyến tính cho ba lớp.

- Đầu vào là chỉ số âm tiết; `nn.Embedding` (Chương 40) biến mỗi chỉ số thành vector 100 chiều, **học cùng** với mạng thay vì học riêng như Word2Vec.
- Âm tiết gặp ít hơn 2 lần trong train được gộp vào `<unk>`; chỉ số 0 dành cho `<pad>`.

## Câu dài ngắn khác nhau

Một lô 64 câu có độ dài khác nhau phải được **đệm** (pad) thêm số 0 cho bằng câu dài nhất để thành một tensor. Nhưng LSTM đọc tới hết chiều dài tensor, nên trạng thái cuối của một câu ngắn sẽ là trạng thái sau khi đọc một loạt `<pad>`, không phải sau từ cuối của câu. Chương 29 đã hứa cách sửa: `pack_padded_sequence` gói lô lại kèm độ dài thật của từng câu, và LSTM dừng đúng ở từ cuối của mỗi câu, không tính trên phần đệm.

```python
import copy
import torch
import torch.nn as nn
import torch.nn.functional as F
from collections import Counter
from torch.nn.utils.rnn import pack_padded_sequence, pad_sequence
torch.set_num_threads(1)

D_tr, D_va, D_te = ([s.split() for s in ds.sentence] for ds in (tr, va, te))   # âm tiết
dem = Counter(w for c in D_tr for w in c)
tu = ["<pad>", "<unk>"] + [w for w, n in dem.items() if n >= 2]
id_ = {w: i for i, w in enumerate(tu)}
ma_hoa = lambda D: [torch.tensor([id_.get(w, 1) for w in c] or [1]) for c in D]   # âm tiết lạ thành <unk>
X_tr, X_va, X_te = ma_hoa(D_tr), ma_hoa(D_va), ma_hoa(D_te)

def lo(X, idx):                                      # đệm một lô, kèm độ dài thật
    xs = [X[i] for i in idx]
    return pad_sequence(xs, batch_first=True), torch.tensor([len(x) for x in xs])

class BiLSTM(nn.Module):
    def __init__(self, V, d=100, h=128):
        super().__init__()
        self.emb = nn.Embedding(V, d, padding_idx=0)
        self.lstm = nn.LSTM(d, h, batch_first=True, bidirectional=True)
        self.ra = nn.Linear(2 * h, 3)
    def forward(self, x, dai):
        goi = pack_padded_sequence(self.emb(x), dai, batch_first=True, enforce_sorted=False)
        _, (h_cuoi, _) = self.lstm(goi)              # trạng thái ở từ cuối thật của mỗi câu, hai chiều
        return self.ra(torch.cat([h_cuoi[0], h_cuoi[1]], 1))

x, dai = lo(X_va, [0, 1, 2])
print(len(tu), x.shape, dai.tolist())
```

## Huấn luyện

Tám epoch, lô 64, Adam (`fused=True` để kết quả lặp lại được trên CPU, như Chương 32). Sau mỗi epoch, đo trên val và **giữ bản tốt nhất** theo macro-F1, như giữ checkpoint ở Chương 35:

```python
def du_doan(m, X):
    m.eval()
    with torch.no_grad():
        x, dai = lo(X, range(len(X)))
        return m(x, dai).argmax(1).numpy()

def huan_luyen(seed, so_epoch=8):
    torch.manual_seed(seed)
    m = BiLSTM(len(tu))
    opt = torch.optim.Adam(m.parameters(), lr=2e-3, fused=True)
    y_t = torch.tensor(y_tr)
    tot, ban_tot = -1, None
    for ep in range(1, so_epoch + 1):
        m.train()
        thu_tu = torch.randperm(len(X_tr))
        for k in range(0, len(thu_tu), 64):
            idx = thu_tu[k:k + 64]
            x, dai = lo(X_tr, idx)
            loss = F.cross_entropy(m(x, dai), y_t[idx])
            opt.zero_grad()
            loss.backward()
            opt.step()
        acc, f1 = cham(du_doan(m, X_va))
        print(ep, acc, f1)
        if f1 > tot:                                 # giữ bản tốt nhất theo macro-F1 trên val
            tot, ban_tot = f1, copy.deepcopy(m)
    return ban_tot

t0 = time.time()
ban_tot = huan_luyen(0)
print(time.time() - t0 < 300)
```

## Chọn và đo test một lần

Ba ứng viên trên val: SVM bigram âm tiết, cùng SVM đó với trọng số lớp cân bằng (trang 3), và BiLSTM. Theo thước đo đã chốt ở trang 1, khi các mô hình gần nhau về độ chính xác thì macro-F1 quyết định. Chọn tự động mô hình có macro-F1 val cao nhất, rồi đo test **một lần**; để tham khảo, in cả hai mô hình còn lại, nhưng con số được báo cáo là của mô hình đã chọn.
